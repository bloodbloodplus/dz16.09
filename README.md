Условие задачи

Дано вещественное число А, содержащее две цифры до запятой и три после. Получить
новое число, поменяв в числе А целую и дробную части. (было 21,317 стало 317,21)



1. Алгоритм и блок-схема

Алгоритм

1.Начало

2.Объявить переменную:
A — исходное вещественное число.

3.Задать исходные данные:
A — вещественное число, содержащее две цифры до запятой и три после.

4.Выделить целую часть числа:
integer_part = целая часть A.

5.Выделить дробную часть числа:
fractional_part = дробная часть A без запятой.

6.Сформировать новое число, поменяв целую и дробную части местами:
new_A = fractional_part + integer_part / 100.

7.Вывести исходное число.

8.Вывести полученное число.

9.Конец.
